# leancoderkavy/homebrew-tap

Homebrew formulae for [Meepo](https://github.com/leancoderkavy/meepo) — a local AI agent that connects LLMs to your digital life.

## Install

```bash
brew install leancoderkavy/tap/meepo
meepo setup
```

## Run as a background service

```bash
brew services start meepo
```

## Update

```bash
brew upgrade meepo
```

## Diagnose issues

```bash
meepo doctor
```
